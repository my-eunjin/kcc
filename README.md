## 📒 kcc 글라스
- 기존 홈페이지를 리뉴얼한 반응형 웹페이지 포트폴리오 입니다.

<br/>

## ✔ 제작 목적
- 기존 KCC 글라스 웹사이트는 모바일 반응형이 잘 적용되어 기능적으로 문제는 없었지만,
  모바일 환경에서의 디자인 완성도가 낮아 시각적으로 아쉬움이 있었습니다.
  또한 이미지의 해상도가 고해상도와 저해상도가 섞여있고, 메뉴의 이미지 사이즈들이 통일되지 않았습니다.
- 이번 리뉴얼에서는 모든 이미지를 고해상도 버전으로 교체하고, 크기를 통일하여 더욱 깔끔하고 일관성 있는 화면을 구현하는 데 중점을 두었습니다.
