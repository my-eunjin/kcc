## 📒 kcc 글라스
- 기존 홈페이지를 리뉴얼한 반응형 웹페이지 포트폴리오 입니다.

<br/>

## ✔ 제작 목적
- 기존 KCC 글라스 웹사이트는 모바일 반응형이 잘 적용되어 기능적으로 문제는 없었지만,<br/>
  모바일 환경과 데스크탑의 레이아웃에서 이미지 해상도와 크기가 불균형하게 섞여 있고<br/>
  메뉴와 콘텐츠의 이미지 크기들이 통일되지 않아 레이아웃이 산만하게 느껴졌습니다.<br/>
- 이번 리뉴얼에서는 모든 이미지를 고해상도로 교체하고 메뉴의 크기를 통일하여<br/>
  레이아웃의 일관성을 개선하고, 더욱 깔끔하고 정돈된 화면을 구현하는 데 중점을 두었습니다.
